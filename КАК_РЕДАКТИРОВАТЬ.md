# Где менять элементы сайта

Сайт состоит из исходников (их редактируете вы) и сгенерированных файлов (они перезаписываются).

## 1. Тексты лекций и тем — `data/plan-lectures.txt`

План лекций:

```
Модуль 1. Название модуля
Лекция 1. Название темы
Первый тезис лекции.
Второй тезис лекции.
Третий тезис лекции.
```

Отсюда берутся названия модулей, лекций и заголовки теоретических блоков.

## 2. Подробное содержание — `course_content.py`

В словаре `LECTURES` для каждой лекции хранятся:

- `goal` — цель лекции;
- `outcomes` — чему научится студент;
- `context` — почему тема важна;
- `blocks` — три подробных теоретических блока;
- `block_notes` — практический вывод;
- `case` — разбор кейса из трёх шагов;
- `pitfalls`, `metrics`, `tools` — ошибки, метрики и инструменты;
- `question`, `refs` — вопрос к обсуждению и источники.

Каждая презентация содержит 15 слайдов. `generate_presentations.py` берёт этот текст из `course_content.py` и создаёт редактируемые файлы PPTX.

После изменений запустите:

```
python generate_presentations.py
python generate_player.py
python generate_site.py
```

## 3. Внутренний проигрыватель — `generate_player.py`

Создаёт страницы `lectures/lecture-*.html` с теми же 15 слайдами, но в виде сайта: слайд занимает две трети ширины, справа расположен прокручиваемый конспект лекции (одна треть). Кнопки «Назад/Далее», точки, клавиши ← → и пробел переключают слайд; конспект автоматически прокручивается к соответствующему фрагменту. Есть режим печати.

После изменений в содержании запустите:

```
python generate_player.py
```

### 3.1. Конспекты — `notes_part1.py` … `notes_part4.py`

Конспекты хранятся в четырёх файлах по четыре лекции в каждом. Внутри каждого файла словарь `NOTES`: ключ — номер лекции, значение — список из 15 фрагментов текста по одному на слайд. Порядок фрагментов совпадает с порядком слайдов.

`lecture_notes.py` объединяет четыре файла в один словарь `NOTES`. Правки вносите в `notes_part*.py`, не в сгенерированные страницы.

Чтобы обновлённый конспект появился на сайте, запустите `python generate_player.py`.

## 4. Главная страница и цвета модулей — `generate_site.py`

- `ACCENTS` — цвета четырёх модулей.
- `render_index()` — заголовок, описание и карточки лекций со ссылками на страницы-проигрыватели.
- `render_references()` — общий список литературы после всех лекций без дополнительных подписей; названия берутся из `refs` в `course_content.py` и из `ADDITIONAL_SOURCES` в `sources.py`, адреса — из `sources.py`. Ссылки открываются в новой вкладке.

После изменений запустите:

```
python generate_site.py
```

## 5. Внешний вид — `assets/style.css`, `assets/app.js`

- `:root { ... }` — цвета, размеры, радиус скругления.
- `.hero h1` — размер заголовка на главной.
- `.lecture-grid` — сетка карточек; `minmax(280px, 1fr)` задаёт минимальную ширину карточки.
- `.reference-list` — общий список литературы и ссылок на главной.
- `.deck-layout` — сетка «слайд 2/3 + конспект 1/3».
- `.slide`, `.controls`, `.dots` — оформление и управление проигрывателя.
- `.notes-panel`, `.notes-body`, `.note-block` — конспект и его прокрутка.
- `assets/app.js` — переключение слайдов и синхронная прокрутка конспекта.

## Что не редактировать вручную

- `index.html` — создаётся `generate_site.py`.
- `lectures/lecture-*.html` — создаются `generate_player.py`.
- `presentations/lecture-*.pptx` — создаются `generate_presentations.py`.

## Как посмотреть сайт

```
python -m http.server 8765
```

Откройте `http://127.0.0.1:8765/`. Карточка лекции ведёт на отдельную страницу: слайды слева, прокручиваемый конспект справа.
